Programação LAVITS 2026

App Android para navegar a programação do VII Simpósio Internacional LAVITS
26 a 28 de agosto de 2026 · Rio de Janeiro

Toda a programação está embutida no app: 79 atividades e 144 trabalhos, com autores, coautores, coordenação e ministrantes. Funciona sem internet e não pede nenhuma permissão — não há acesso a rede, localização ou qualquer sensor.

O que o app faz

  • Três abas de dia (26, 27, 28 de agosto) com as atividades agrupadas por horário.
  • Busca por autor, instituição, título, código ou palavra-chave — insensível a acentos e maiúsculas, cobrindo os três dias de uma vez.
  • Filtros por tipo: sessões temáticas, sessões livres, oficinas, práticas artísticas e tramas.
  • Minha agenda: favorite atividades e veja avisos automáticos de conflito de horário entre trilhas paralelas.
  • Tema claro e escuro, seguindo a configuração do sistema.

Usar agora

🌐 Abrir o webapp

Mesma programação, direto no navegador — sem instalar nada. Favoritos ficam salvos neste navegador/aparelho.

Instalar o app Android

O app ainda não está em nenhuma loja.

⬇ Baixar o APK

O Android pode avisar que o app é de "fonte desconhecida" — é normal para APKs fora da Play Store; permita a instalação para prosseguir.

Alternativamente, para gerar o APK a partir do código-fonte:

git clone https://github.com/rafaaevangelista/programacaolavits.git
cd programacaolavits
./gradlew assembleDebug
